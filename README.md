# ET Image Studio

可持续复用的 Etsy 帽子商品图工作台。

## 工作流程

1. 上传帽子正面、侧面、背面和细节参考图。
2. 补充已确认的真实产品信息。
3. 生成 960 × 768 低清预览。
4. 单独修改每张图的要求并重新生成。
5. 确认构图后生成高清图。
6. 高清请求按 3008 × 2400 生成，浏览器自动居中裁切为 3000 × 2400 JPG。

## 图片服务

长期使用时，在运行环境设置 `OPENAI_API_KEY`。临时使用也可以在工作台的“图片服务连接”中输入，密钥只保留在当前页面内，不写入浏览器存储。

## 固定视觉风格

温暖自然光、真实面料纹理、低饱和中性色、现代手作品牌感、轻微编辑杂志风；避免过度磨皮、虚化、HDR 和明显的 AI/CGI 质感。
